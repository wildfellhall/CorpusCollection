# CorpusCollection
The worst part (in my opinion) of training my models is always collecting the books for the corpus, so I'm assembling all of my lists here. 
Unless explicitly noted in the docstring of that particular corpus itself, all sources will be from before 1900 (subsequent publishing dates not withstanding). 
Note that many of the smaller corpuses were originally utilized for fine-tuning rather than training from scratch, so as I shift their purposes, the lengths will begin to change.
